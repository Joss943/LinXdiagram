# Contribuer

Merci de votre intérêt pour LinXdiagram !

* Ouvrez un ticket pour signaler un bug ou proposer une fonction (pour une faille de sécurité,
  voir [SECURITY.md](SECURITY.md)).
* Les propositions de code passent par une *pull request* ; lancez les tests avant :
  `python3 -m unittest discover -s tests -t .`
* En contribuant, vous acceptez que votre contribution soit publiée sous licence MIT et
  certifiez en avoir le droit (pas de code, d'image ou de fichier copié d'un logiciel
  propriétaire, notamment de Microsoft).
* Ne joignez pas de données personnelles (noms, adresses, documents réels) aux tickets ou
  fichiers d'exemple.
